# Moving Average Calculator

## Overview
This project is a simple Python package that calculates the moving average of a list of floating-point numbers. The package includes a function `moving_average` in `app/stats.py` and unit tests in `tests/test_stats.py` to ensure its correctness.

## Features
- Calculates the moving average of a list of floats.
- Raises a `ValueError` if the `window` parameter is less than 1.
- Returns an empty list if the `window` parameter is greater than the number of values in the `values` list.
- Correctly calculates the moving average for every run of `window` consecutive values in the `values` list.
