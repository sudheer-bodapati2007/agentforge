# TodoStore Implementation

## Overview

The `TodoStore` class is a simple in-memory implementation for managing todos. It provides methods to add, retrieve, list, update, and delete todos with proper error handling.

## Features

- **Add Todo**: Creates a new todo with a unique id and returns it as a dictionary.
- **Get Todo**: Retrieves a todo by its id, raising a `KeyError` if the id does not exist.
- **List Todos**: Returns all todos ordered by id.
- **Update Todo**: Updates a todo's title and/or done status, raising a `KeyError` if the id does not exist, and returns the updated todo.
- **Delete Todo**: Removes a todo by its id, raising a `KeyError` if the id does not exist.
- **Error Handling**: Raises `ValueError` if the title is empty or only whitespace.
