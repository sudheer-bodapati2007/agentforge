# Slugify Function and Tests

## Overview
This project contains a Python function `slugify` located in `app/slug.py` and comprehensive pytest tests for it in `tests/test_slug.py`. The `slugify` function processes input strings to convert them to a slugified format, which is useful for creating URL-friendly strings.

## Features
- Converts input strings to lowercase.
- Replaces non-alphanumeric characters with hyphens.
- Strips leading and trailing hyphens.
- Handles various edge cases, including empty strings and strings with only non-alphanumeric characters.
