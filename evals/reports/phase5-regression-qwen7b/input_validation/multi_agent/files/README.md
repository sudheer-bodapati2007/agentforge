# User Registration Validation

## Overview
This project contains a Python function `validate_registration` in `app/validation.py` that validates user registration data according to specified rules. The function ensures that the `username`, `email`, and `age` fields meet certain criteria and returns a new dictionary with the validated data.

## Features
- Validates `username`, `email`, and `age` fields.
- Strips and lowercases `username` and `email` fields.
- Converts `age` to an integer.
- Raises `ValueError` for invalid fields and `TypeError` for non-dictionary inputs.
