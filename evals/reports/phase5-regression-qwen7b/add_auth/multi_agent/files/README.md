## FastAPI Notes App with API-Key Authentication

### Overview
This project is a FastAPI application for managing notes with API-key authentication. The `/notes` endpoints require a valid API key in the `X-API-Key` header, while the `/health` endpoint remains public.

### Features
- **API-Key Authentication**: Secure access to `/notes` endpoints using a constant-time key comparison.
- **Public `/health` Endpoint**: Stay public, no API key required.
- **CRUD Operations**: Basic CRUD operations for managing notes.

### Setup
1. **Install Dependencies**: Ensure you have Python installed. Then, create a virtual environment and install the required packages:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   pip install fastapi uvicorn pydantic
   ```
2. **Set Environment Variable**: Set the `NOTES_API_KEY` environment variable to a valid API key:
   ```bash
   export NOTES_API_KEY=your_valid_api_key
   ```

### Environment Variables
- **NOTES_API_KEY**: The API key used for authentication. Must be set and contain a valid key.

### How to Run
1. **Run the Application**: Start the FastAPI application using Uvicorn:
   ```bash
   uvicorn app.main:app --reload
   ```
2. **Access the Application**: Open your browser and navigate to `http://127.0.0.1:8000/docs` to access the interactive API documentation.

### API Endpoints
- **GET /health**: Stay public, no API key required.
- **GET /notes**: Retrieve all notes. Requires a valid API key.
- **POST /notes**: Create a new note. Requires a valid API key.

### How to Run the Tests
1. **Run the Tests**: Execute the tests using Pytest:
   ```bash
   pytest tests/test_main.py
   ```

### Architecture Decisions
- **FastAPI**: Used for building the web application.
- **Pydantic**: Used for data validation.
- **Constant-Time Key Comparison**: Ensured using `hmac.compare_digest` for security.
