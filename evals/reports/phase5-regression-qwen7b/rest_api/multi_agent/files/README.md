# Item Management API

This project is a small REST API built with FastAPI to manage items in memory. The API provides endpoints to create, retrieve, and list items, along with a health check endpoint.

## Features
- **Health Check**: Returns `{'status': 'ok'}` to indicate the API is running.
- **Create Item**: Adds a new item with a unique ID and returns it.
- **Retrieve Item**: Fetches an item by its ID.
- **List Items**: Returns a list of all items, ordered by ID.
- **Validation**: Ensures `name` is not missing, empty, or only whitespace, and `price` is non-negative.

## Setup

## Environment Variables
No environment variables are required for this project.

## How to Run
1. Start the FastAPI server using `uvicorn app.main:app --reload`.
2. Access the API endpoints using a tool like `curl`, Postman, or any HTTP client.

## API Endpoints
- **GET /health**: Returns `{'status': 'ok'}`.
- **POST /items**: Takes a JSON body `{'name': str, 'price': float}` and responds with status 201 and `{'id': int, 'name': str, 'price': float}`.
- **GET /items/{item_id}**: Returns the item with the given ID or status 404 if no item has that ID.
- **GET /items**: Returns the list of all items, ordered by ID.
