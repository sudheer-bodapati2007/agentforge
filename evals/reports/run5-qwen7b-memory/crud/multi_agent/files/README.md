# TodoStore Implementation

## Overview
This project contains a `TodoStore` class in `app/todos.py` that manages todos in memory. Each instance of `TodoStore` maintains its own data and provides methods to add, get, list, update, and delete todos with specific error handling.

## Features
- **Add Todo**: Creates and returns a new todo with a unique id, stripped title, and default `done` status of `False`.
- **Get Todo**: Returns a todo by its id, raising `KeyError` if the id does not exist.
- **List Todos**: Returns all todos ordered by id.
- **Update Todo**: Updates a todo by its id, changing only the provided arguments, and returns the updated todo. Raises `KeyError` if the id does not exist.
- **Delete Todo**: Removes a todo by its id, raising `KeyError` if the id does not exist.
- **Error Handling**: Includes error handling for edge cases and invalid input.
