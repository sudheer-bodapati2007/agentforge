# Item Management API with FastAPI

## Overview
This project is a small REST API built with FastAPI to manage items in memory. It includes endpoints for creating, retrieving, and listing items, as well as a health check endpoint.

## Features
- **Health Check**: Returns the health status of the API.
- **Create Item**: Adds a new item to the inventory and returns the item with its ID.
- **Retrieve Item**: Returns the item with the specified ID.
- **List Items**: Returns a list of all items, ordered by ID.

## Setup
1. Clone the repository.
2. Navigate to the project directory.
3. Install dependencies:
   ```bash
   pip install fastapi uvicorn pytest httpx
   ```

## Environment Variables
No environment variables are required for this project.

## How to Run
1. Start the FastAPI server:
   ```bash
   uvicorn app.main:app --reload
   ```
2. Access the API endpoints using a tool like `curl`, Postman, or any other HTTP client.

## API Endpoints
- **GET /health**: Returns the health status of the API.
- **POST /items**: Adds a new item to the inventory and returns the item with its ID.
- **GET /items/{item_id}**: Returns the item with the specified ID.
- **GET /items**: Returns a list of all items, ordered by ID.

## How to Run the Tests

## Architecture Decisions
- **FastAPI**: Used for building the REST API.
- **Pydantic**: Used for data validation.
- **In-memory Storage**: Items are stored in a dictionary in memory.
