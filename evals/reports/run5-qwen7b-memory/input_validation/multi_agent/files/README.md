# User Registration Validation

## Overview
This project contains a Python function `validate_registration` in the `app/validation.py` file to validate user registration data according to specified rules. The function checks the `username`, `email`, and `age` fields and raises `ValueError` or `TypeError` if the data is invalid.

## Features
- Validates `username` to be 3 to 20 characters long and contain only letters, digits, and underscores.
- Validates `email` to contain exactly one `@`, with at least one character before it, and the part after it must contain a dot that is neither its first nor its last character.
- Validates `age` to be an integer between 13 and 120 inclusive.
- Raises `TypeError` if the input is not a dictionary.
- Raises `ValueError` with a message that contains the name of the first invalid field.
