# FastAPI Notes App with API-key Authentication

## Overview
This project is a FastAPI application for managing notes with API-key authentication. The `/notes` endpoints require the `X-API-Key` header to match the value of the `NOTES_API_KEY` environment variable. The `GET /health` endpoint remains public.

## Features
- API-key authentication for `/notes` endpoints.
- Public `GET /health` endpoint.
- Constant-time key comparison using `hmac.compare_digest`.

## Setup
1. Clone the repository.
2. Set the `NOTES_API_KEY` environment variable.
3. Install dependencies: `pip install fastapi uvicorn pydantic`
4. Run the application: `uvicorn app.main:app --reload`

## Environment Variables
- `NOTES_API_KEY`: The API key used for authentication. Must be set and contain a valid API key.

## How to Run
1. Start the application using `uvicorn app.main:app --reload`.
2. Access the application at `http://127.0.0.1:8000`.

## API Endpoints
### GET /health
- **Description**: Public endpoint to check the health of the application.
- **Response**: `{"status": "ok"}`

### GET /notes
- **Description**: List notes. Requires API-key authentication.
- **Headers**: `X-API-Key`
- **Response**: List of notes

### POST /notes
- **Description**: Add a new note. Requires API-key authentication.
- **Headers**: `X-API-Key`
- **Request Body**: `{"text": "Note text"}`
- **Response**: `{"id": 1, "text": "Note text"}`

## How to Run the Tests
1. Set the `NOTES_API_KEY` environment variable to `test_key`.
2. Run the tests using `pytest tests/test_main.py`.
