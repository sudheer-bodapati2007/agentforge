# Library Catalogue Project

## Overview
This project is a small library catalogue backed by a PostgreSQL database. It includes functions to manage authors and books, ensuring specific constraints are enforced. The project is implemented using Python 3.12, SQLAlchemy Core, and pytest for testing.

## Features
- **Authors Table**: Stores author information with a unique name.
- **Books Table**: Stores book information with a reference to the author and constraints on the year.
- **Functions**:
  - `add_author(name: str) -> int`: Adds a new author and returns their ID.
  - `add_book(author_id: int, title: str, year: int) -> int`: Adds a new book and returns its ID.
  - `books_by(author_id: int) -> list[str]`: Returns a list of book titles by an author, ordered by year and title.
  - `delete_author(author_id: int) -> None`: Deletes an author and all their books.
