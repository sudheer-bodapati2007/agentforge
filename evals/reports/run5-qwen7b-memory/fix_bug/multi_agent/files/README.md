# Moving Average Calculator

## Overview
This project is focused on fixing a bug in the `moving_average` function located in `app/stats.py`. The function is designed to calculate the moving average of a list of float values with a specified window size. This README provides details on how to set up the project, run it, and test the `moving_average` function.

## Features
- Calculate the moving average of a list of float values with a specified window size.
- Raise a `ValueError` if the window size is less than 1.
- Return an empty list if the window size is larger than the number of values.
- Return the average of every run of `window` consecutive values in order.
