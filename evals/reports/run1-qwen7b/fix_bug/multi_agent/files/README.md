# Moving Average Calculator

## Overview
This project contains a function `moving_average` in `app/stats.py` that calculates the moving average of a list of numeric values. The function also includes error handling for invalid inputs.

## Features
- Calculates the moving average of a list of numeric values.
- Raises a `ValueError` if the window size is less than 1.
- Returns an empty list if the window size is larger than the number of values.
