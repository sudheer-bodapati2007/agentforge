# User Registration Data Validation Project

## Overview
This project implements a function to validate user registration data according to specified rules. The function `validate_registration` is located in `app/validation.py` and is designed to handle user input, validate it, and return the validated data or raise appropriate exceptions if the input is invalid.

## Features
- Validates `username`, `email`, and `age` fields.
- Strips surrounding whitespace and lowercases `username` and `email`.
- Converts `age` to an integer.
- Raises `ValueError` for invalid fields and `TypeError` for non-dictionary inputs.
