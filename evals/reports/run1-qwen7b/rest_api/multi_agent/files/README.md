# Item Management API with FastAPI

## Overview
This project is a small REST API built with FastAPI to manage items in memory. It includes endpoints for creating, retrieving, and listing items, as well as a health check endpoint.

## Features
- **Health Check**: `/health` - Returns `{'status': 'ok'}` if the service is up.
- **Create Item**: `/items` - Accepts a JSON body with `{'name': str, 'price': float}` and returns the new item with a positive integer id.
- **Retrieve Item**: `/items/{item_id}` - Returns the item with the given id or 404 if not found.
- **List Items**: `/items` - Returns a list of all items, ordered by id.

1. Start the FastAPI server:
   ```bash

   ```
2. Access the API endpoints using a tool like `curl`, Postman, or any other HTTP client.

## API Endpoints
- **GET /health**: Returns `{'status': 'ok'}`.
- **POST /items**: Creates a new item and returns it with a positive integer id.
- **GET /items/{item_id}**: Returns the item with the given id or 404 if not found.
- **GET /items**: Returns a list of all items, ordered by id.
