# TodoStore Implementation

## Overview
This project implements a `TodoStore` class in `app/todos.py` that manages todos in memory. The class provides methods to add, get, list, update, and delete todos. Each todo has a unique id, and the store handles errors for non-existent ids and empty titles. All returned dictionaries are copies to prevent changes to the store.

## Features
- **Add Todo**: Creates a new todo with a unique id, strips the title, and returns a dictionary with the todo's id, title, and done status.
- **Get Todo**: Returns a todo by its id, raising a `KeyError` if the id does not exist.
- **List Todos**: Returns all todos ordered by id.
- **Update Todo**: Updates a todo's title and/or done status, raising a `KeyError` if the id does not exist.
- **Delete Todo**: Removes a todo by its id, raising a `KeyError` if the id does not exist.
- **Error Handling**: Raises `ValueError` for empty or whitespace-only titles and `KeyError` for non-existent ids.
- **Data Copies**: Returns copies of the todo dictionaries to prevent changes to the store.
