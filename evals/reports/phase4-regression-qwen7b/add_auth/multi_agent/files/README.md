## FastAPI Notes App with API-Key Authentication

### Overview
This project is a FastAPI application for managing notes with API-key authentication. The `/notes` endpoints require a valid API key to be provided in the `X-API-Key` header. The `/health` endpoint remains public and accessible without authentication.

### Features
- **API-Key Authentication**: The `/notes` endpoints require a valid API key to be provided in the `X-API-Key` header. The key is compared in constant time using `hmac.compare_digest`.
- **Public `/health` Endpoint**: The `/health` endpoint remains public and accessible without authentication.
- **Note Management**: The application allows users to list and add notes.

### Setup
1. Clone the repository.
2. Set the `NOTES_API_KEY` environment variable.
3. Install dependencies: `pip install fastapi uvicorn pydantic`
4. Run the application: `uvicorn app.main:app --reload`

### Environment Variables
- `NOTES_API_KEY`: The API key required for accessing the `/notes` endpoints.

### How to Run
1. Start the application using `uvicorn app.main:app --reload`.
2. Access the `/health` endpoint to check the application's health: `GET /health`.
3. Access the `/notes` endpoints to list and add notes: `GET /notes` and `POST /notes`.

### API Endpoints
- **GET /health**: Public endpoint to check the health of the application.
- **GET /notes**: List notes. Requires API key authentication.
- **POST /notes**: Add a new note. Requires API key authentication.

### How to Run the Tests
1. Set the `NOTES_API_KEY` environment variable to `test_key`.
2. Run the tests using `pytest tests/test_main.py`.

### Architecture Decisions
- **FastAPI**: Used for the web framework.
- **Pydantic**: Used for data validation.
- **Constant-Time Comparison**: `hmac.compare_digest` is used for API key comparison to prevent timing attacks.
