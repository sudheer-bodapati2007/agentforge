# FastAPI Item API

This project is a small REST API built using FastAPI. The API provides endpoints for health check, item creation, item retrieval by ID, and retrieval of all items. Items are stored in memory, and input data is validated.

## Features
- **Health Check**: A `GET /health` endpoint that returns `{'status': 'ok'}`.
- **Item Creation**: A `POST /items` endpoint that accepts a JSON body `{'name': str, 'price': float}` and returns status 201 with `{'id': int, 'name': str, 'price': float}`. Each new item receives a unique positive integer ID.
- **Item Retrieval**: A `GET /items/{item_id}` endpoint that returns the item with the given ID or status 404 if no item has that ID.
- **Item List**: A `GET /items` endpoint that returns a list of all items, ordered by ID.
- **Input Validation**: Validation is performed on the input data for the `POST /items` endpoint to ensure `name` is not empty and `price` is non-negative.

1. Start the FastAPI server using `uvicorn app.main:app --reload`.
2. Access the API endpoints using a tool like Postman or curl.

## API Endpoints
- **GET /health**: Returns `{'status': 'ok'}`.
- **POST /items**: Accepts a JSON body `{'name': str, 'price': float}` and returns `{'id': int, 'name': str, 'price': float}` with status 201.
- **GET /items/{item_id}**: Returns the item with the given ID or status 404 if no item has that ID.
- **GET /items**: Returns a list of all items, ordered by ID.
