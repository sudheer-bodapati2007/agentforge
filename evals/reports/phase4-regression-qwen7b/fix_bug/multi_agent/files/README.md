# Moving Average Calculator

## Overview
This project is a simple Python application that calculates the moving average of a list of floating-point numbers. The application includes a function `moving_average` in the `app/stats.py` file and unit tests for this function in the `tests/stats_test.py` file.

## Features
- Calculates the moving average of a list of floating-point numbers.
- Raises a `ValueError` if the `window` parameter is less than 1.
- Returns an empty list if the `window` parameter is larger than the number of values in the `values` list.
- Returns the correct average of every run of `window` consecutive values in the `values` list.
