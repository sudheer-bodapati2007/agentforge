## Project README

### Overview
This project contains a Python function `slugify` located in `app/slug.py` and a set of comprehensive pytest tests in `tests/test_slug.py`. The `slugify` function processes input text to create a slug format, ensuring it is in lowercase, non-alphanumeric characters are replaced with hyphens, and leading and trailing hyphens are stripped. The tests cover various edge cases to ensure the function behaves as expected.

### Features
- **slugify Function**: Converts input text to a slug format.
- **pytest Tests**: Comprehensive tests to validate the `slugify` function's behavior under different input conditions.
