# Moving Average Fix Project

## Overview
This project fixes a bug in the `moving_average` function located in `app/stats.py`. The function is updated to handle edge cases correctly, raise a `ValueError` when `window` is less than 1, and return an empty list when `window` is larger than the number of values. Unit tests are also provided to ensure the function behaves as expected.

## Features
- Fixed bug in the `moving_average` function
- Handles edge cases correctly
- Raises `ValueError` when `window` is less than 1
- Returns an empty list when `window` is larger than the number of values
- Returns the average of every run of `window` consecutive values, in order
