# TodoStore Implementation

## Overview
This project implements a `TodoStore` class in `app/todos.py` that manages todos in memory. The class provides methods for adding, retrieving, listing, updating, and deleting todos with error handling.

## Features
- **Add Todo**: Creates and returns a new todo with a unique id, stripped title, and default `done` status of `False`.
- **Get Todo**: Returns a todo by its id, raising `KeyError` if the id does not exist.
- **List Todos**: Returns all todos ordered by id.
- **Update Todo**: Updates a todo by its id, only changing non-None arguments, and returns the updated todo, raising `KeyError` if the id does not exist.
- **Delete Todo**: Removes a todo by its id, raising `KeyError` if the id does not exist.
- **Error Handling**: Raises `ValueError` if the title is empty or only whitespace.
- **Data Copies**: Ensures that all returned dicts are copies to prevent changes to the store.
