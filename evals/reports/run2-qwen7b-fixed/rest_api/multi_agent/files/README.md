## Project Overview

This project is a small REST API built with FastAPI to manage items in memory. It includes endpoints for creating, retrieving, and listing items, as well as a health check endpoint.

## Features

- **Health Check**: A `GET /health` endpoint that returns `{'status': 'ok'}`.
- **Item Management**: Endpoints to create, retrieve, and list items.
  - `POST /items`: Create a new item and return it with a unique id.
  - `GET /items/{item_id}`: Retrieve the item with the given id.
  - `GET /items`: Retrieve the list of all items, ordered by id.
