## Overview
This project consists of a Python module `app/slug.py` that contains a function `slugify` for converting text to a slug. Additionally, there are tests for this function in `tests/test_slug.py` using the `pytest` framework.

## Features
- The `slugify` function raises a `TypeError` if the input is not a string.
- The `slugify` function converts the input text to lowercase.
- The `slugify` function replaces all non-alphanumeric characters with hyphens.
- The `slugify` function removes leading and trailing hyphens from the resulting slug.
