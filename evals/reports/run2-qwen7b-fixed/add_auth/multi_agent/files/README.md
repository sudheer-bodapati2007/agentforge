## FastAPI Notes API with API-key Authentication

This project is a FastAPI application that adds API-key authentication to the `/notes` endpoints. The `/notes` endpoints require the `X-API-Key` header to match the value of the `NOTES_API_KEY` environment variable. The `GET /health` endpoint remains public and does not require authentication.

### Features
- API-key authentication for `/notes` endpoints.
- Constant-time key comparison using `hmac.compare_digest`.
- Public `GET /health` endpoint.

### Setup
1. Set the `NOTES_API_KEY` environment variable.
2. Install dependencies: `pip install fastapi uvicorn pydantic`
3. Run the application: `uvicorn app.main:app --reload`

### Environment Variables
- `NOTES_API_KEY`: The API key used for authentication.

### How to Run
1. Set the `NOTES_API_KEY` environment variable.
2. Run the application using `uvicorn app.main:app --reload`.

### API Endpoints
- `GET /health`: Returns the health status of the application. Public endpoint.
- `GET /notes`: Lists all notes. Requires API-key authentication.
- `POST /notes`: Adds a new note. Requires API-key authentication.

### How to Run the Tests
